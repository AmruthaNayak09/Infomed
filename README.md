# InfoMed – Smart Doctor-Patient Management System

InfoMed is a secure web-based application designed to streamline doctor–patient interactions using facial recognition for patient identification and efficient medical record management.

## Features
- Facial recognition-based patient identification  
- Secure login and access to patient data  
- Doctor–patient portal for managing medical records  
- Automated form filling and report generation  
- User-friendly web interface  

## Tech Stack
- Python  
- Flask  
- OpenCV  
- Face Recognition  
- HTML, CSS  

## Project Objective
To improve efficiency and security in healthcare systems by reducing manual data entry and enabling fast, accurate patient identification.
